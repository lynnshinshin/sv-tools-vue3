一、扩展简介

SV Tools 是一款考勤辅助浏览器扩展（Chrome / Edge），面向使用公司考勤系统的员工，提供考勤数据展示、加班时间参考、加班申请表单自动填充与个人加班计划编排等功能。本政策说明扩展访问哪些信息、如何处理这些信息，以及您如何控制与删除它们。

二、我们访问的信息

扩展仅在您的浏览器本地读取和处理以下信息，用于页面展示与计算：

  • 考勤数据：今日上/下班打卡时间、当月加班时长与明细、当日日历类型（工作日/休息日）。这些数据由扩展在您打开的考勤系统页面中本地解析获得；
  • 您主动输入的信息：请假时间段、加班原因及其历史记录、加班类型偏好、用于收益估算的底薪数字、自定义背景图片；
  • 偏好设置：主题（亮/暗）、各功能开关、周末加班勾选状态等。

三、信息的使用方式

上述信息仅用于在本扩展界面内计算与展示（如下班时间、加班参考列表、月度加班汇总与收益估算），不用于任何其他目的。

四、信息的存储

所有数据均存储在您设备上浏览器的 chrome.storage.local 本地存储区中。扩展没有任何自有服务器，不向任何服务器上传数据。

五、我们不做什么

  • 不收集您的浏览历史；
  • 不向任何第三方提供、共享或出售您的任何数据；
  • 不集成任何分析、统计、追踪或广告 SDK；
  • 不在扩展外部传输您的考勤数据或个人输入。
扩展监听考勤系统页面的网络请求完成事件，仅用于判断"数据已加载完成"以触发本地解析，不会记录或存储请求内容。

六、权限说明

  • storage：在本地保存上述数据与偏好；
  • webRequest：监听公司考勤系统（*.gaiaworkforce.com）接口的完成事件，用于触发本地数据解析；
  • tabs：在您主动发起读取或申请时，打开/关闭考勤系统页面；
  • alarms：实现"工作日定时读取打卡"的本地定时任务；
  • idle：判断电脑是否活跃，避免在不合适的时间自动打开页面打扰您；
  • 主机权限（*.gaiaworkforce.com）：仅用于在考勤系统页面内注入脚本完成数据解析与表单填充。

七、数据的删除

您可随时通过扩展内的"设置 → 清除本地缓存"一键删除全部本地数据；卸载扩展时，浏览器会自动删除其全部本地存储。数据不会在任何其他地方留有副本。

八、政策的变更

如扩展功能变化导致本政策需要更新，我们会更新本页面并修改页面顶部的生效日期。

九、联系方式

对本政策或扩展有任何疑问，可通过 GitHub 联系开发者：https://github.com/lynnshinshin。

1. Overview

SV Tools is a browser extension (Chrome / Edge) for employees of companies using the Gaiawork attendance system. It provides attendance information display, overtime reference calculations, automatic filling of overtime application forms, and personal overtime planning. This policy explains what information the extension accesses, how that information is handled, and how you can control and delete it.

2. Information We Access

The extension reads and processes the following information locally in your browser, solely for display and calculation within the extension:

  • Attendance data: today's clock-in/out times, monthly overtime totals and details, and the calendar type of the day (workday / rest day). This data is parsed locally from the attendance system pages you open; the extension does not query any server by itself;
  • Information you enter voluntarily: leave time ranges, overtime reasons and their history, overtime type preferences, a base-salary figure used for earnings estimation, and custom background images;
  • Preferences: theme (light/dark), feature toggles, weekend-overtime checkbox state, etc.

3. How the Information Is Used

All of the above is used only for calculation and display inside the extension (e.g., estimated end-of-work time, overtime reference lists, monthly overtime summaries and earnings estimates). It is not used for any other purpose.

4. Data Storage

All data is stored in your browser's local storage area (chrome.storage.local) on your device. The extension operates no servers of its own and does not upload any data to any server.

5. What We Do Not Do

  • We do not collect your browsing history;
  • We do not share, provide, or sell any of your data to any third party;
  • We do not integrate any analytics, statistics, tracking, or advertising SDKs;
  • We do not transmit your attendance data or personal inputs outside the extension.
The extension listens for the completion of network requests made by the attendance system pages. This is used only to detect that "data has finished loading" so local parsing can start; request contents are neither recorded nor stored.

6. Permissions Explanation

  • storage — store the above data and preferences locally;
  • webRequest — observe request-completion events of the company attendance system (*.gaiaworkforce.com) to trigger local parsing;
  • tabs — open or close attendance system pages when you initiate a read or an application;
  • alarms — schedule the local "fetch attendance on workdays" task;
  • idle — check whether the computer is active, so the extension avoids opening pages at inconvenient times;
  • Host permission (*.gaiaworkforce.com) — used only to inject the content scripts that parse data and fill forms on the attendance system pages.

7. Data Deletion

You can delete all locally stored data at any time via "Settings → Clear local cache" inside the extension. Uninstalling the extension removes all of its local storage automatically. No copies of the data exist anywhere else.

8. Changes to This Policy

If a future version of the extension changes how information is handled, this page will be updated and the effective date at the top will be revised accordingly.

9. Contact

For any questions about this policy or the extension, contact the developer via GitHub: https://github.com/lynnshinshin.
